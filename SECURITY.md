# Security

Project Steward is local-first and inspects repository content. Treat `.project/` as committed and potentially public.

Please do not report security issues in public issues. Send a private report to the repository owner until a dedicated security contact is published.

Before any write path ships, Project Steward must include prompt and ledger redaction controls. Until then, do not store secrets, customer data, credentials, or private incident details in committed project records.
