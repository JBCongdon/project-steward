# Assumptions

- TypeScript/Node is an acceptable first OSS implementation stack because it lowers contribution friction and keeps MCP integration straightforward.
- The first valuable user workflow is read-only audit plus baseline ratcheting.
- Apache-2.0 is an acceptable initial open-source license because the project may later attract commercial and enterprise contributors.
- Static analysis language support should be added as independently tested detector modules rather than one monolithic analyzer.
